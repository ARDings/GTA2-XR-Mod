# GTA2Ceiling (Deutsch)

GTA2 als lebende Miniaturstadt an der echten Decke oder auf dem Boden, in Mixed Reality auf einer eigenständigen Meta Quest 3. Der Raum bleibt per Passthrough sichtbar; die originale Spielsimulation läuft, gesteuert mit einem Xbox-Controller. Kein PC beim Spielen nötig.

**Status:** experimentelle Vorschau, Hobbyprojekt.

**Eigene GTA2-Kopie nötig.** Dieses Repository enthält keine Spieldateien, und es werden keine heruntergeladen oder weitergegeben. Grand Theft Auto und GTA2 sind Marken ihrer jeweiligen Inhaber; kein Bezug zu ihnen.
